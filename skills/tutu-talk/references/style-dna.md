# 风格 DNA

## 一句话

简约单线平涂手绘简笔画，卡通速写风，低复杂度儿童简笔质感。

像一张在白纸上用单线快速勾画的童趣小画，温暖、简单、干净。

## 必须

- 16:9 横版正文配图。
- 白底为主，底部或局部用浅绿色草地块点缀——草地只上色块，无线稿草叶。
- 单线勾勒：细线、轻微抖动、不机械、不厚重描边。
- 画面干净：主体占画面约 40%-60%，留出足够空白区域。
- 少量中文手写批注：最多 5-8 处，每处尽量 2-8 个字。
- 一张图只讲一个核心动作、结构、状态或故事。
- 结构要自然表达，不要在图上写结构类型名称。

## 颜色

- **黑色**：主体线稿、狗狗轮廓与五官、框线、结构、主要文字。
- **浅米黄**：突突狗狗身体主体色，单色无渐变。
- **浅绿色**：标注主要使用色，与草地背景协调。
- **浅绿色块**：草地或局部铺色。
- **橙色**：重点提醒、关键标注、路径箭头。
- **浅蓝色**：次要说明、附加信息、狗狗配件（可选胸背带/项圈）。
- **浅蓝色线稿（可选）**：用于云朵、水流等轻柔元素。

不再使用红色。颜色要克制，宁可少不要多。

## 绝对不要

- 不要商业插画。
- 不要写实风格。
- 不要复杂线稿或高密度线条。
- 不要怪诞/荒诞/暗黑风格。
- 不要阴影或渐变。
- 不要 PPT 信息图或正式流程图。
- 不要科技感 UI 或真实 App 截图。
- 不要复杂背景、纹理、噪点。
- 不要把每个节点都解释清楚。
- 不要左上角写"Workflow / 流程图 / 系统架构图 / 常见坑"等类型标题。

## 审美方向

要童趣、可爱、简单、温暖、干净。

不要复杂、死板、暗黑、商业感。
