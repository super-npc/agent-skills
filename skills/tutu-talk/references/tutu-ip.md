# 突突 IP

## 角色定义

突突是正文配图的固定视觉 IP——一只浅米黄色的单色狗狗。

每张图都要出现突突。突突不是贴纸，不是纯装饰，而是正在认真参与画面故事的温暖小主角。

## 参考风格

参考图：见 `assets/tutu.jpg`（金毛/拉布拉多幼犬风格的浅棕色狗狗，表情开心、吐舌头、穿浅蓝色胸背带，坐在浅绿色草地上）。以此为写实度基准，做轻微卡通化处理。

## 外形

- **颜色**：浅米黄单色，不渐变、不添加阴影层次。
- **头**：圆脑袋，弱化细节。
- **耳朵**：耷拉的半圆耳朵。
- **四肢**：短粗，略带圆润感。
- **尾巴**：蓬松简化，可画成简单的绒球或小扇形。
- **眼睛**：黑色圆点或小弧线，表达开心/好奇/温暖的表情。
- **配件**：可选——可带浅蓝色胸背带/项圈等小配件，增加辨识度；大部分场景纯色即可。
- **轮廓**：单线勾勒，轻微抖动，有手绘简笔质感。

## 性格

- 温暖、好奇、呆萌。
- 认真参与画面中的事情——看路标、叼东西、追球、趴着观察。
- 不卖弄，不复杂。像一只真实的幼犬，单纯地存在于画面里。
- 情绪外显：开心吐舌头、歪头疑惑、趴着放松、跑起来兴奋。

## 常见动作

让突突承担与画面主题相关的动作：

- **坐 / 趴 / 躺**：安静状态，观察、等待、思考。
- **跑 / 跳**：动态状态，追逐、前进、兴奋。
- **嗅**：探索、发现、好奇。
- **叼**：搬运、传递、参与流程。
- **翻滚 / 打滚**：开心、放松、玩耍。
- **歪头**：疑惑、好奇、在听。
- **打盹**：放松、休息、低能耗状态。
- **摇尾巴**：开心、期待、友好。
- **刨土**：积极行动、探索。
- **伸懒腰**：开始/结束一个阶段。
- **探头 / 观望**：等待、好奇、从某处出现。

## 颜色规范

- 突突主体：浅米黄，单色无渐变。
- 配件（如有）：浅蓝色胸背带或项圈。
- 眼睛/鼻子/线稿：黑色细线。

## 禁止

- 不要写实毛发细节。
- 不要复杂的明暗阴影。
- 不要画成真实照片风格。
- 不要给突突添加过多配件或服饰。
- 不要让突突只是站在角落当装饰——必须是画面核心参与者。
- 不要有渐变或阴影层次。

## 判断标准

如果去掉突突，图的核心意思还能完全成立，说明突突太装饰了——需要调整构图，让突突成为动作主体。
